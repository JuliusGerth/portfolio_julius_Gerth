Design System

Over dit projectAbout this project

Voor dit project heb ik een eigen design system gebouwd in Figma. Het design system bevat herbruikbare componenten, een kleurenpalet, typografieregels en spacing-afspraken. Het doel was om een consistente visuele taal te creëren die je kunt toepassen op verschillende projecten.

For this project I built my own design system in Figma. The design system contains reusable components, a colour palette, typography rules and spacing conventions. The goal was to create a consistent visual language that you can apply across different projects.

FunctiesFeatures

  • Kleurenpalet met primaire, secundaire en neutrale tinten
  • Typografische schaal met duidelijke hiërarchie
  • Herbruikbare UI-componenten (knoppen, invoervelden, kaarten)
  • Spacing- en grid-systeem
  • Colour palette with primary, secondary and neutral tones
  • Typographic scale with a clear hierarchy
  • Reusable UI components (buttons, input fields, cards)
  • Spacing and grid system

Gebruikte technologieënTechnologies Used

  • Figma: herbruikbare componenten en gedeelde kleur- en tekststijlen
  • Figma: reusable components and shared colour and text styles
